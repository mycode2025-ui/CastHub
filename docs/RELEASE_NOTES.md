新增**应用内升级检测**：设置 → 关于 → 检查更新，冷启动也会静默查一次（6 小时内不重复）。

同时查询 GitHub 与 Gitee 的 Release，取版本更高的一条；某个数据源取不到时，结论里会带出告警 —— 因为此时"已是最新"可能是漏判的。

可在应用内下载安装包并调起系统安装器。安装包只允许从受信 https 域名下载，下载后会校验签名与本机一致，不一致直接删除并拒装。

主要修复：

· 设置页切换协议开关、改名不再卡住主线程（实测此前掉 37 帧）
· 接收服务列表此前只显示一个模块，AirPlay 那行被吞掉
· 待机页在 1080p 电视上近一半内容看不到，且遥控器滚不动 → 改为双列版式
· 投屏态遥控器 ←/→ 快进时灵时不灵（方向键被全屏视频层吞掉）
· HTTP 请求体按不可信的 Content-Length 无上限分配，可被同网段主机打崩
· 多标签域名的 mDNS 查询会越界崩溃；AirPlay 的 TXT 超长条目会写出损坏报文

⚠️ 本版本首次改用**专用发布签名**（此前是 debug 签名）。如果你装过 1.4.0 之前用 debug 签名构建的包，**无法覆盖安装**，需要先卸载旧版。从本版本起签名固定，后续版本可以正常覆盖升级。

`minSdk 23`（Android 6.0），`targetSdk 34`。首次安装需在系统设置里允许「安装未知应用」。
